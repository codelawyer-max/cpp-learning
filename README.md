# C++ Learning

This repository contains my code from a C++ web series, along with two console projects built using the C++ STL (Standard Template Library).

## Structure

- `first.cpp` to `thirtysecond.cpp`: practice programs and exercises from the web series, in order
- `employeemanagementstl.cpp/`: Employee Management project
- `onlinestoreusingstl.cpp/`: Online Store project

## Projects

### 1. Employee Management (STL)
A console program that manages employee records using STL containers and algorithms. It can:
- Sort employees by salary
- List employees with high salaries
- Calculate total and average salary
- Find the highest paid employee

### 2. Online Store (STL)
A console program that simulates a simple online store using STL containers.

## How to Compile and Run

Make sure you have a C++ compiler (g++) installed. Then, inside a project folder:

    g++ main.cpp -o main
    .\main

## Topics Covered

- C++ basics, loops, functions, and arrays
- Object-oriented programming
- STL containers and algorithms
